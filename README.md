# alien_invasion
A ship that fires bullets.

In the Alien Invasion project, I have used the Pygame package to develop a 2D game. 
The goal of the game is to shoot down a fleet of alines as they drop down the screen, in levels that increase in speed and difficulty.

I have split the project into two developmental phase.
Phase 1 - I am gonna create a rocket ship that moves left or right and fires bullets in response to the user's input.
Phase 2 - I am going to create a fleet of aliens to destroy and continue to refine the game by setting limits on the number of ships we can use and add a scoreboard.
